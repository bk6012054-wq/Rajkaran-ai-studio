RAJKARAN AI STUDIO - STARTER PACKAGE

यह अभी installable web app (PWA) का शुरुआती प्रोजेक्ट है, Android APK नहीं।

माइक्रोफोन जरूरी:
- इसे HTTPS वेबसाइट पर चलाएँ (उदाहरण: GitHub Pages)।
- फोन में Chrome site settings > Microphone > Allow करें।
- डाउनलोड की हुई HTML फाइल को content:// से खोलने पर microphone access ब्लॉक हो सकता है।

इस संस्करण में:
- रिकॉर्डिंग
- बैकग्राउंड म्यूजिक फाइल चुनना
- बेसिक Echo/Reverb-जैसे प्रभाव और EQ
- ऑडियो मिक्स डाउनलोड (ब्राउज़र समर्थित WebM/MP4 फॉर्मेट)

अभी शामिल नहीं:
- AI AutoTune / pitch correction
- असली noise removal
- MP3 export
- APK पैकेजिंग

इसे HTTPS पर होस्ट करने के बाद Android Chrome मेन्यू > Add to Home screen से होम स्क्रीन पर जोड़ा जा सकता है।
